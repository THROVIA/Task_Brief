# Changelog

## 1.0.0

Initial public-release edition of Task Brief · 开工前对齐.

- Six checks for aligning intent, subject, scope, deliverables, and completion criteria before complex work.
- Explicit handling of omissions, disagreements, existing authorization, and changes to the working definition.
- A four-round limit for the same task definition, with unresolved decisions kept visible.
- Direct handling of simple tasks and continuity for already aligned work.
- Bilingual discovery description, English runtime instructions, and bilingual user documentation.
- MIT licensing.

首次正式公开版本：提供开工前六步对齐、四轮收束、简单任务直接处理与已对齐任务接续；附双语说明及 MIT 许可证。

### Packaging revision R1 — 2026-10-15

- Moved `SKILL.md` to the repository root for a single-skill layout.

- Kept the approved skill instructions and MIT license unchanged.

This date records the packaging revision, not a GitHub release event. The skill version remains 1.0.0.
